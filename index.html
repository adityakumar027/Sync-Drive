⚡ Open Source Android Sync

Resilient Android Cloud Synchronization

Mirror device folders to your Google Drive account with resumable 8MB chunked uploads, 4 parallel workers, and automated error recovery.

Download APK (v1.1.0) View on GitHub

🚀 Resumable Chunking

Large files (>20MB) upload in 8MB chunks. If a connection drops, it resumes from the last byte instead of restarting.

⚡ 4 Parallel Workers

Multiple files upload simultaneously using WorkManager foreground background services with live progress.

🧠 Smart Deduplication

Detects existing files by exact size and name to prevent redundant data usage and duplicate uploads.
